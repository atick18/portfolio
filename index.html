Cipher Desk — Details

A lightweight in-browser tool for encoding and decoding text with several classic ciphers. Pick a method, set a key if the cipher needs one, and run the message through — everything happens locally, so nothing is sent to a server.

Supported Methods
  • Caesar Cipher (shift-based)
  • Vigenère Cipher (keyword-based)
  • Atbash Cipher (alphabet reversal)
  • XOR Cipher
  • Reverse Encoding
  • 100% client-side — no data leaves the browser
